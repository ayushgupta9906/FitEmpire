# FitEmpire

FitEmpire is India's next-generation fitness membership platform where users can discover gyms, purchase memberships, book classes, check in using QR codes, earn rewards, receive AI-powered fitness recommendations, and manage their entire fitness journey from a single app.

This is a production-ready ecosystem featuring:
- **Backend**: Spring Boot 3 / Java 21 / PostgreSQL / Redis
- **Admin Portal**: React / Vite / Material UI
- **Mobile Client**: React Native / Expo Router
