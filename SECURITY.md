# Security Policy

FitEmpire takes the security and privacy of our fitness members and gym partners seriously.

## Supported Versions
| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability
If you discover a security vulnerability within FitEmpire, please disclose it responsibly:
- **Email**: security@fitempire.tech
- **PGP Key**: Available upon request
- **Response SLA**: We acknowledge reports within 24 hours and aim to provide fixes within 72 hours for critical severity findings.

Please do **NOT** open public GitHub issues for security vulnerabilities.
